# ⚙️ Engenharia de Software

Repositório dedicado ao armazenamento e à documentação das atividades práticas da disciplina de Engenharia de Software do curso de Análise e Desenvolvimento de Sistemas (ADS).

## 🛠️ Tecnologias e Ferramentas

As tecnologias e ferramentas utilizadas variam conforme os objetivos e requisitos de cada atividade.

- **Versionamento:** Git e GitHub 
- **Documentação:** Markdown (`.md`) 
- **Prototipação e Desenvolvimento:** Ferramentas e tecnologias específicas de cada atividade.

## 📂 Organização do Repositório

O repositório é organizado por atividades, mantendo seus respectivos materiais, protótipos, registros e documentações em diretórios separados.

Cada diretório contém os arquivos relacionados à execução e à entrega da atividade correspondente.
